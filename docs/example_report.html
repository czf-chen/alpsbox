6. Methods and processing settings

ALPS = mean(Dxx_proj, Dxx_asso) / mean(Dyy_proj, Dzz_asso)

ROI: 2.5 mm radius spheres on the JHU-ICBM-FA-1mm template, 81 voxels per region
     (matching the 5 mm diameter of the original Taoka 2017 paper)
Registration: FA → JHU-ICBM-FA-1mm, flirt 12 DOF, cost function normmi
Tensor reorientation: vecreg (T' = R·T·Rᵀ, Alexander 2001; Tatekawa 2023)
Gibbs unringing: True    denoising (dwidenoise): False    bet -f: 0.50
These are the processing settings actually used for this result; check every parameter before comparing with other studies. ALPS is sensitive to preprocessing (brain-extraction threshold, registration cost, template, denoising, etc.), and results from different definitions should not be mixed directly.
